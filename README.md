# مُراجَعة عِلمِ العَرُوضِ السَّريعة (`arudh-uts`)

تطبيق ويب تفاعلي باللغة العربية الفصحى للمستوى الابتدائي، مُصمَّم للمراجعة السريعة للامتحان من كتاب **«الكافي في العروض والقوافي»** للخطيب التبريزي (ص ٧٣–١٠٨)، ويشمل:

1. **معمل التقطيع التدريجي:** جميع الشواهد الـ ٧٤ (الهزج، الرجز، الرمل، دائرة المشتبه، السريع، المنسرح) مع كشف خطوة بخطوة (الكتابة العروضية ← الرموز `/ o` ← التفعيلات ← الحالة ونوع البيت والشرح).
2. **البطاقات السريعة (Flashcards):** للمراجعة النشطة مع خيار إظهار تلميح البحر والخلط العشوائي.
3. **محاكي الزحاف والعلل والمعاقبة والمكانفة:** عرض بصري للحروف المحذوفة والمتغيرة في التفعيلات الأربع + تجربة تفاعلية للمعاقبة والمكانفة لكل بحر.
4. **الدائرة الثالثة التفاعلية (دائرة المشتبه):** شرح مرئي لقواعد فكّ البحور الخمس.
5. **محاكي الامتحان:** أسئلة مستخرجة من شواهد وقواعد الكتاب مع تصحيح فوري وخيار إعادة الأسئلة الخاطئة فقط.

## تشغيل التطبيق عبر GitHub Pages
لفتح التطبيق مباشرة على iPad أو الهاتف، فعّل **GitHub Pages** من إعدادات المستودع:
`Settings → Pages → Build and deployment → Source: Deploy from a branch (main / root)`.
